# AI & Machine Learning Portfolio

A 50-day hands-on learning journey covering Python programming, Data Analysis, Machine Learning, Deep Learning, Audio Processing, Automatic Speech Recognition (ASR), and Natural Language Processing (NLP).

This repository brings together practical exercises, implementations, experiments, and end-to-end projects developed throughout this learning path. It demonstrates the progression from programming fundamentals and data analysis to machine learning applications and AI-powered systems.

## Learning Roadmap

| Area | Coverage | Days |
|---|---|---|
| Python Basics | Core Python programming and practical applications | 01–07 |
| Data Analysis | Data manipulation, exploration, and visualization | 08–13 |
| Machine Learning | Data preprocessing, model training, and evaluation | 14–20 |
| Deep Learning | Neural networks and image classification | 21–29 |
| Audio Processing | Digital audio fundamentals and audio feature extraction | 30–36 |
| Automatic Speech Recognition | Speech processing and speech-to-text systems | 37–42 |
| Natural Language Processing | Text processing, NLP techniques, and language-based applications | 43–48 |
| Final Project | Development and improvement of a voice assistant | 49–50 |

## Learning Approach

This portfolio follows a practical, project-oriented learning approach:

- Building foundational programming skills before moving to advanced AI topics.
- Applying theoretical concepts through hands-on coding exercises.
- Working with real-world datasets and different data formats.
- Implementing and evaluating machine learning and deep learning models.
- Developing integrated applications that combine multiple AI components.
- Improving projects through iterative development and evaluation.
