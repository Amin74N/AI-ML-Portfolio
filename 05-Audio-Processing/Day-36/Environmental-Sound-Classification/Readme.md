# Environmental Sound Classification

## Frameworks & Libraries
- Python
- PyTorch
- Librosa
- NumPy
- Pandas
- Matplotlib
- Scikit-learn

## Dataset
- UrbanSound8K
- 8,732 audio clips
- CSV annotation file
- 10 predefined folds
- 10 environmental sound classes:
  - Air Conditioner
  - Car Horn
  - Children Playing
  - Dog Bark
  - Drilling
  - Engine Idling
  - Gun Shot
  - Jackhammer
  - Siren
  - Street Music

## Learning Outcomes
- Building an end-to-end environmental sound classification pipeline
- Creating a custom PyTorch Dataset for audio processing
- Preprocessing raw audio recordings using Librosa
- Generating Mel Spectrogram features for deep learning models
- Designing and training a Convolutional Neural Network (CNN)
- Applying Batch Normalization and Dropout to improve model generalization
- Training models using the Adam optimizer and Cross Entropy Loss
- Scheduling the learning rate during training
- Saving and reloading the best-performing model
- Evaluating classification performance using Accuracy, Precision, Recall, and F1-Score
- Visualizing training history and confusion matrices
- Performing predictions on unseen audio samples with confidence scores
